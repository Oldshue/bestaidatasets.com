What are the best AI datasets in 2026?

Last updated: 2026-11-09

The best single place to find AI datasets is the Hugging Face Hub. Use Kaggle for easy-to-use community datasets with free notebooks. For training language models, start with Common Crawl and the filtered corpora built from it, such as FineWeb and Dolma. For image, video and text data, look at LAION. The right choice depends on your task and on each dataset's license, so check both before you train on anything.

The ranked list

  1. Hugging Face Hub (Datasets)

    What it is: The largest hub built specifically for AI datasets. Each dataset is a Git repository with a dataset card, and many also have an interactive Dataset Viewer. You can filter by task, language and license.

    Best for: Almost everyone building machine learning or AI models, especially for text, speech, vision and large training corpora.

    Strengths: Versioned Git-backed repos, dataset cards, search filters, and public or private visibility for organizations. It also hosts major corpora such as FineWeb and Dolma.

    Drawbacks: Most datasets are uploaded by the community, so quality and documentation vary. Some datasets are gated or have the viewer turned off.

    Pricing: Browsing and downloading public datasets is free. Free accounts get 100GB of private storage. Paid plans add more storage: the public storage add-on costs $12/TB/month, and extra private storage is $18/TB/month at the base rate (per Hugging Face's storage documentation).

    Official site: huggingface.co/datasets

  2. Kaggle Datasets

    What it is: Google-owned Kaggle's public dataset catalog, connected to its hosted notebooks and competitions. Kaggle said it had more than 500,000 public datasets as of February 2025.

    Best for: Learners, data scientists and applied projects that want data and free compute in one place.

    Strengths: You can open a notebook straight from a dataset page, and notebooks offer optional free GPU/TPU. Downloads work through the official Kaggle CLI or the KaggleHub library. Public datasets can be downloaded through the API without an API key.

    Drawbacks: Quality varies between uploads. Each dataset has its own license chosen by the uploader, and compute quotas apply.

    Pricing: Free to view, download and analyze public datasets.

    Official site: kaggle.com/datasets

  3. Common Crawl

    What it is: A nonprofit web archive with petabytes of raw web pages, metadata and extracted text, collected regularly since 2008. The newest crawl listed today is CC-MAIN-2026-43.

    Best for: Teams building their own web-scale text corpora for language-model pretraining.

    Strengths: Huge scale and new crawls throughout the year. Access through Amazon's hosting is free. It also offers URL and CDXJ indexes, web graphs, and a public opt-out ledger.

    Drawbacks: It is raw material. Before training you need serious filtering, deduplication, safety processing, rights review and a lot of compute.

    Pricing: Free to access. You pay for your own compute.

    Official site: commoncrawl.org

  4. FineWeb (Hugging Face)

    What it is: A filtered English web corpus built from Common Crawl and published on the Hugging Face Hub under the ODC-By license. It is split into one subset per crawl, plus 10B-, 100B- and 350B-token samples.

    Best for: LLM pretraining and data-ablation research when you don't want to filter Common Crawl yourself.

    Strengths: Filtering is already done, it has an open license, and the sample sizes are good for small experiments. It loads directly from the Hub.

    Drawbacks: English only, and very large. It inherits whatever rights and privacy questions apply to the underlying web content.

    Pricing: Free download.

    Official site: huggingface.co/datasets/HuggingFaceFW/fineweb

  5. Dolma (Allen Institute for AI)

    What it is: An open pretraining corpus of 3 trillion tokens. It mixes web content, academic papers, code, books and encyclopedia material, and it was used to train AI2's OLMo models.

    Best for: Researchers who want a fully documented, reproducible mixed-source pretraining corpus.

    Strengths: ODC-BY license (since April 2024), a datasheet and paper, open-source curation tools, a stats table for each source, a 16.4GB sample of about 10 billion tokens, and a form for requesting removal of personal data.

    Drawbacks: The newest version (v1.7) came out in April 2024, so most of its sources stop in 2023. The full set is 4.5TB compressed.

    Pricing: Free download.

    Official site: huggingface.co/datasets/allenai/dolma

  6. LAION (Re-LAION-5B and LAION-BVD)

    What it is: A nonprofit that publishes open multimodal datasets. Re-LAION-5B (August 2024) has 5.5 billion text–image-link pairs with extra safety fixes. LAION-BVD (August 2026) is a video dataset with 1.3 billion video URLs, 80 million downloaded videos (10 million hours), 55 million captioned clips and 300 million captioned frames.

    Best for: Pretraining vision-language and video-language models.

    Strengths: Huge scale, both research and research-safe versions, and open tools for working with the data (img2dataset, CLIP Retrieval, CLIP Benchmark).

    Drawbacks: The image data is mostly links, so you have to download and filter the content yourself. LAION has replaced older releases such as the original LAION-5B.

    Pricing: Free.

    Official site: laion.ai/projects

  7. Google Dataset Search

    What it is: A search engine for datasets. It indexes datasets from thousands of repositories across the web using schema.org markup.

    Best for: Finding scientific, government or niche datasets when you don't know where they're hosted.

    Strengths: Searches across many repositories at once and helps you find datasets that can be cited.

    Drawbacks: It only finds and links to datasets. It doesn't host them, and its coverage depends on publishers adding markup.

    Pricing: Free.

    Official site: datasetsearch.research.google.com

  8. Registry of Open Data on AWS

    What it is: AWS's catalog of datasets you can use through AWS, from sources such as NASA, NOAA, NIH, EPA, AI2 and Data for Good at Meta. It includes usage examples and SageMaker Studio Lab tutorials.

    Best for: Very large scientific, geospatial, genomics and web datasets that you want to process in the cloud.

    Strengths: Cloud-scale data such as Common Crawl, Sentinel-2 and The Cancer Genome Atlas, with documented usage examples.

    Drawbacks: Unless stated otherwise, AWS does not provide or maintain the datasets. Each one has its own third-party license.

    Pricing: The registry is free to browse. Your compute costs depend on how you process the data.

    Official site: registry.opendata.aws

  9. UCI Machine Learning Repository

    What it is: UC Irvine's long-running repository, with 690 datasets, including classics such as Iris, Wine Quality and Bank Marketing.

    Best for: Teaching, classical ML benchmarks and tabular experiments.

    Strengths: Well-known, frequently cited datasets with clear metadata, and new datasets are still being added.

    Drawbacks: Datasets are small by modern AI standards, and it is not a source for training foundation models.

    Pricing: Free.

    Official site: archive.ics.uci.edu

  10. OpenML

    What it is: An open machine learning platform that stores every dataset in Parquet so it can be loaded the same way through its Python, R and Java clients.

    Best for: Benchmarking and AutoML on tabular data.

    Strengths: A single loader for all datasets and integration with scikit-learn, mlr, Weka and PyTorch. Many UCI datasets are mirrored there.

    Drawbacks: Mainly tabular data; image support uses header tables. Our automated reader was blocked from the homepage, so this entry relies on OpenML's official documentation.

    Pricing: Free.

    Official site: openml.org

  11. Google BigQuery public datasets

    What it is: Datasets hosted in BigQuery through the Google Cloud Public Dataset Program. Google pays for storage, and you query the data with SQL.

    Best for: Analysts and ML engineers who want to query large structured datasets in SQL without downloading them.

    Strengths: The first 1TB of queries per month is free. Access works through the console, the bq CLI, the API and client libraries.

    Drawbacks: Requires a Google Cloud project and charges for queries above the free tier. The program has no SLA.

    Pricing: Pay per query after the first free 1TB/month.

    Official site: cloud.google.com/bigquery/public-data

  12. Azure Open Datasets

    What it is: Microsoft's curated, preprocessed public datasets covering weather, census, holidays, public safety, location and transportation (for example, NYC taxi trips). They are built into Azure Machine Learning and Azure Databricks.

    Best for: Adding features to predictive models, especially for teams already on Azure.

    Strengths: The data is cleaned and enriched before it reaches you. You can load it from any Python environment without an Azure account.

    Drawbacks: The catalog is small and focused on enrichment data, not model training corpora.

    Pricing: Free datasets. Azure compute is billed separately.

    Official site: azure.microsoft.com/services/open-datasets

  13. Data.gov

    What it is: The US government's open data catalog, listing 532,480 datasets as of today.

    Best for: Public-sector, geospatial, economic and civic datasets.

    Strengths: Huge official coverage, organized by agency, with metrics on usage.

    Drawbacks: Formats and quality vary widely. Most of it isn't packaged ready for ML.

    Pricing: Free.

    Official site: data.gov

  14. Zenodo

    What it is: A general research repository run by CERN since May 2013. It has no requirements on format, size or license, and it issues citable records through DataCite.

    Best for: Finding the datasets published alongside academic papers, and publishing your own with a DOI.

    Strengths: Citable records, embargoes and restricted access, and an API.

    Drawbacks: It isn't designed around ML, so how well datasets are documented and how easy they are to find varies.

    Pricing: Free.

    Official site: zenodo.org

How to choose

  • Start from the task, not the size. For LLM pretraining, look at Common Crawl, FineWeb or Dolma. For vision-language work, look at LAION. For tabular benchmarks, use UCI or OpenML. For fine-tuning on a specific task, search Hugging Face and Kaggle.
  • Read the license and the source. A license on a collection may not cover every underlying work. Check the dataset card, the upstream terms, and whether consent and personal data have been handled.
  • Check how fresh it is. Look at version dates and data cutoffs. For example, Dolma's newest version came out in April 2024, while Common Crawl publishes new crawls throughout the year.
  • Plan for compute and storage. Corpora measured in terabytes or petabytes mean real processing costs. Cloud-hosted options (AWS, BigQuery, Azure) let you process the data where it's stored.
  • Prefer documented datasets. Dataset cards, datasheets, versioning and removal processes make data easier to trust and to defend.
  • Need licensed or custom-labeled data instead? Open datasets may not cover proprietary or human-labeled needs. In that case, look at commercial training-data vendors.

FAQ

What is the best place to find AI datasets?

For most people, the Hugging Face Hub is the best starting point. It is built for AI datasets and lets you filter by task, language and license. Kaggle is a close second, especially if you want free notebooks. Use Google Dataset Search when you don't know where a dataset is hosted.

Are these AI datasets free to use commercially?

Not automatically. Access is usually free, but each dataset has its own license, and a license on a collection may not grant rights to every underlying work. Read the license and dataset card before any commercial use.

What datasets are used to train large language models?

Open LLM pretraining usually starts with web data from Common Crawl, then adds filtered corpora such as FineWeb and mixed corpora such as Dolma, which combines web, academic, code, book and encyclopedia sources.

Where can I find large image-text or video datasets?

LAION publishes Re-LAION-5B, with 5.5 billion text–image-link pairs, and LAION-BVD, a video dataset with 80 million downloaded videos and 55 million captioned clips. Both are aimed at multimodal pretraining research.

Where can I find small, classic datasets for learning machine learning?

The UCI Machine Learning Repository (690 datasets, including Iris and Wine Quality) and OpenML are the standard sources. Kaggle is also good for beginner-friendly projects.

How do I download a dataset programmatically?

On Hugging Face, use the datasets or huggingface_hub Python libraries. On Kaggle, use the Kaggle CLI or KaggleHub; public datasets can be downloaded without an API key. On OpenML, use openml.datasets.get_dataset in Python. For BigQuery public datasets, use SQL through the console, the bq CLI or the API.

Do I need a cloud account to use cloud-hosted public datasets?

For BigQuery public datasets, you need a Google Cloud project, and the first 1TB of queries per month is free. Azure Open Datasets can be accessed from any Python environment without an Azure account. Common Crawl data on AWS is free to access.

What is the difference between a dataset hub and a dataset search engine?

A hub such as Hugging Face or Kaggle hosts the data itself. A search engine such as Google Dataset Search indexes datasets hosted elsewhere and sends you to the original publisher.
